API Reference

Base URL: https://api.novadocs.example.com/v1. All requests require an Authorization: Bearer <token> header.

Authentication

Generate an API token in Settings → API Tokens. Tokens are workspace-scoped and can be restricted to read-only.

Endpoints

GET /spaces

Returns all spaces the authenticated user can access.

curl https://api.novadocs.example.com/v1/spaces \
  -H "Authorization: Bearer $TOKEN"

GET /spaces/:id/documents

Lists all documents in a space. Supports pagination via ?page= and ?per_page=.

POST /spaces/:id/documents

Creates a new document. Body: {"title": "string", "content": "markdown string"}

GET /documents/:id

Returns a single document including its full content and metadata.

DELETE /documents/:id

Permanently deletes a document. This cannot be undone.

Rate limits

The API is rate-limited to 1,000 requests per minute per workspace. The response headers include X-RateLimit-Remaining and X-RateLimit-Reset.
