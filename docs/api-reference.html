API Reference

Base URL: https://api.ConversiveDocs.example.com/v1. All requests require an Authorization: Bearer <token> header.

Authentication

Generate an API token in Settings → API Tokens. Tokens are workspace-scoped and can be restricted to read-only.

Endpoints

GET /spaces

Returns all spaces the authenticated user can access.

curl https://api.ConversiveDocs.example.com/v1/spaces \
  -H "Authorization: Bearer $TOKEN"

GET /spaces/:id/documents

Lists all documents in a space. Supports pagination via ?page= and ?per_page=.

POST /spaces/:id/documents

Creates a new document. Body: {"title": "string", "content": "markdown string"}

GET /documents/:id

Returns a single document including its full content and metadata.

DELETE /documents/:id

Permanently deletes a document. This cannot be undone.

Request parameters

ParameterTypeRequiredDescription
titlestringYesDocument title. Max 255 characters.
contentstringYesDocument body in Markdown format.
space_idstringYesThe ID of the space to create the document in.
parent_idstringNoID of a parent document (for nested docs).
tagsstring[]NoArray of tag strings. Max 10 tags per document.

Response fields

contentstringDocument body in Markdown.

author_idstringUser ID of the document creator.
created_atISO 8601Timestamp when the document was created.
updated_atISO 8601Timestamp of the last edit.
summarystringAI-generated summary (Pro/Enterprise only).

Error codes

CodeHTTP StatusMeaning
unauthorized401Missing or invalid API token.
forbidden403Token does not have access to this resource.
not_found404Document or space does not exist.
validation_error422Request body failed validation. Check errors array.
rate_limited429Too many requests. Wait for X-RateLimit-Reset.
server_error500Internal error. Contact support if it persists.

Rate limits

The API is rate-limited to 1,000 requests per minute per workspace. The response headers include X-RateLimit-Remaining and X-RateLimit-Reset.
