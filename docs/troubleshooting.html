Troubleshooting

Common issues and how to fix them. If your issue isn't listed here, contact support@conversive.ai.

Login

I can't log in — the page keeps redirecting

This is usually caused by a stale session cookie. Fix it in three steps:

  1. Clear cookies for app.conversive.ai in your browser settings.
  2. Open a private/incognito window and try logging in again.
  3. If SSO is enabled for your workspace, confirm your identity provider session hasn't expired.
Search

Search returns no results even though the document exists

New documents take up to 60 seconds to be indexed after they are saved. If the document is older than that:

  • Check that you have at least Viewer access to the space the document is in.
  • Try searching by the exact title in quotes, e.g. "Q3 Roadmap".
  • If the document was recently imported, re-index it from Settings → Import → Re-index.
Integrations

Slack notifications stopped arriving

Slack notifications fail when the OAuth token expires or is revoked. Go to Settings → Integrations → Slack and click Reconnect. If the workspace admin revoked the app, they will need to re-approve it in Slack's App Management.

API

API requests return 401 even with a valid token

Check these in order:

  1. The token must be sent as Authorization: Bearer <token> — not as a query param.
  2. Tokens are workspace-scoped. Confirm the token was generated in the same workspace as the resource.
  3. Read-only tokens cannot write. Generate a read-write token from Settings → API Tokens.
Performance

The editor is slow when a document is very long

Documents over 50,000 words may render slowly in the full editor. Workarounds:

  • Split the document into sections using the Split Document option in the ⋯ menu.
  • Use Outline view (View → Outline) to navigate without rendering the full body.
  • Disable real-time collaborators' cursors from View → Hide Collaborators to reduce re-renders.
