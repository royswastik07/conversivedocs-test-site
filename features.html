Smart Search

Full-text and semantic search across all your documents. New in v3.0: search now includes voice input and returns results in under 200ms even on workspaces with over 1 million pages.

Real-time Collaboration

Multiple teammates can edit documents simultaneously. New in v3.0: threaded comments and inline suggestions — reviewers can now propose edits without changing the original text.

Integrations

ConversiveDocs connects with Slack, Jira, GitHub, Figma, Notion, and now Linear and Zendesk. New in v3.0: two-way sync — changes in Jira tickets automatically update linked documents.

AI-Powered Summaries

Every document gets an AI-generated summary. New in v3.0: summaries now include a "key decisions" section that extracts action items and decisions from meeting notes automatically.

Access Control

Set permissions at the workspace, space, or page level. New in v3.0: role templates — define a permission bundle once and apply it to new members in one click.

Analytics Dashboard

New in v3.0: the analytics dashboard now includes search query reports — see exactly what your team searched for but couldn't find, so you know which docs to write next.
