Changelog

Every release, documented. Subscribe to updates at changelog@conversive.ai.

v3.0 Major October 7, 2026
New Features
  • Voice input for Smart Search — speak your query, get results in under 200ms
  • Threaded comments and inline suggestions in the editor
  • Linear and Zendesk integrations added
  • Two-way Jira sync — Jira ticket updates now reflect in linked documents
  • AI summary "Key Decisions" section — extracts action items from meeting notes
  • Role templates for one-click permission bundles
  • Analytics: search query reports show what users searched but couldn't find
Improvements
  • Search index rebuilt — results now return 40% faster on average
  • Editor performance improved for documents over 50,000 words
  • API rate limit increased from 500 to 1,000 requests per minute
Bug Fixes
  • Fixed: Slack notifications occasionally sent twice on document publish
  • Fixed: Table of contents not updating after heading edits
  • Fixed: Guest links ignoring expiry setting on Safari
v2.0 Major September 1, 2026
New Features
  • AI-powered summaries now available in 12 languages
  • Time-limited guest links (7, 30, or 90-day expiry)
  • Analytics dashboard — view counts, top contributors, unread pages
  • Notion added to integrations
  • Version history extended to 365 days
Bug Fixes
  • Fixed: Import from Confluence losing table formatting
  • Fixed: PDF export cutting off content on pages with large images
v1.0 Minor July 15, 2026
New Features
  • Real-time collaboration with color-coded cursors
  • REST API v1 — stable and production-ready
  • AI-powered document summaries
  • Slack, Jira, GitHub, and Figma integrations
